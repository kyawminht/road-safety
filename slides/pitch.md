# 🚦 Road Safety for Myanmar Children — Product Intro

## The Problem

- Myanmar has one of the highest road fatality rates in Southeast Asia
- Children are particularly vulnerable
- Most schools lack projectors or screens for interactive learning
- Existing materials are outdated, text-heavy, and not engaging

## The Solution

A mobile-first learning app that teaches road safety through:
- Visual flip cards (no reading required)
- Interactive games with animations and sound effects
- Simple Burmese captions

## Key Features

### Learning Modules
- Visual flip cards — tap to flip between wrong (❌) and right (✅)
- 5 safety topics: Walking, Helmet, Sidecar, Bicycle, Tricycle
- 14+ real-world scenarios
- Fully in Burmese

### Interactive Games
- **Be Bright Be Seen** — Visibility awareness with day/night scenes
- **Spot the Danger** — Hazard detection practice
- **Pedestrian First** — Right of way driving simulation

### Game Features
- Animated characters with walking animations
- Sound effects (correct, wrong, police siren)
- Yes/No quiz questions
- Score tracking and retry option

## Target Audience

- Myanmar children ages 6–17
- Teachers in schools without technology
- Parents teaching road safety at home

## How It Works

1. Children pick a topic or game
2. See scenarios through visual cards or animations
3. Learn through color, icons, and simple captions
4. Practice with interactive quizzes
5. Get immediate feedback

## Tech Stack

- React + Framer Motion
- Canvas API for game graphics
- Web Audio API for sound effects
- Tailwind CSS
- Mobile-first design (320px–428px)

## Impact

- Works on any phone, no app store required
- Teacher-friendly — PDF download for printing
- Culturally relevant for Myanmar
- Engaging visual-first approach
